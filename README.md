# **Seedarrt.com** - Galerie E-commerce d'Art

*Plateforme e-commerce haut de gamme dédiée à l'art pictural et 3D*

---

## **À propos du projet**

**Seedarrt.com** est une boutique en ligne élégante conçue pour un artiste peintre. La plateforme présente et vend des œuvres d'art dans un environnement numérique raffiné.

### **Vision**
Offrir une expérience d'achat premium pour découvrir et acquérir des œuvres d'art originales.

---

## **Stack Technique**

**Frontend:** HTML5, CSS3, JavaScript - Design responsive  
**Backend:** PHP avec architecture MVC  
**Base de données:** MySQL  

**Fonctionnalités principales:**
- Panier intelligent avec gestion des stocks
- Système d'authentification sécurisé  
- Processus de commande fluide
- Design responsive
- Galerie optimisée pour l'affichage des œuvres

---

## **Contexte de développement**

Premier projet fullstack complet développé sur mon temps libre dans un objectif de formation.
